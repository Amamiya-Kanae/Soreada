Soreada蘇打閱讀

免費、開源的 Android EPUB／TXT 閱讀器。把摺疊屏與平板變成一本書：直向一頁、展開兩頁，留白乾淨，沒有訂閱與廣告。

FEATURES

為閱讀而做的細節

不是把所有功能塞進同一個畫面，而是把翻頁、排版與顯示做好。

01

摺疊屏與平板寬屏

依視窗尺寸自動切換單頁、雙頁；外屏或窄視窗不會硬塞兩頁。

02

漫畫與文字

支援 EPUB 圖像 spine、TXT 編碼辨識；漫畫與長篇文字都能讀。

03

護眼與紙張顆粒

暖色濾鏡與閱讀頁顆粒，強度可調，長時間閱讀更舒服。

04

書籤與快速跳轉

進度條圓點直接跳頁；文字書的書籤以字元位置保存。

05

雙指縮放

漫畫頁支援 1×–4× 縮放，放大後可單指拖動。

06

三語與 Material 3

繁中、簡中、English 即時切換；支援深色模式與現代介面。

FOLDABLE & TABLET

一個版面，不被裝置綁死

Soreada 依目前視窗寬高決定版面，不綁定特定機型；展開、摺疊、旋轉都會保留目前頁。

  • 內屏直向：完整一頁，白色留白
  • 內屏橫向／平板寬屏：左右雙頁
  • 外屏／窄視窗：維持單頁
  • 展開、摺疊、旋轉：保留頁碼，文字重新排版

SCREENSHOTS

看它實際閱讀的樣子

書庫、第一次開書提示，與摺疊屏橫向雙頁。

FAQ

常見問題

真的免費嗎？

是。Soreada 是 MIT 授權的開源專案，沒有廣告、訂閱或付費牆。

支援哪些格式？

EPUB 2/3 與 TXT。目前不支援 DRM、CBZ/CBR、PDF。

支援摺疊屏和平板嗎？

支援。內屏直向單頁、橫向雙頁；平板寬屏也是雙頁，外屏維持單頁。

書庫會同步嗎？

書庫存在裝置本機，不需要帳號；換裝置需重新匯入。

如何回報問題？

到 GitHub Issues 開 Issue，附上裝置型號、Android 版本與重現步驟。
