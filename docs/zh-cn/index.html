Soreada苏打阅读

免费、开源的 Android EPUB／TXT 阅读器。把折叠屏与平板变成一本书：直向一页、展开两页，留白干净，没有订阅与广告。

FEATURES

为阅读而做的细节

不是把所有功能塞进同一个画面，而是把翻页、排版与显示做好。

01

折叠屏与平板宽屏

根据窗口尺寸自动切换单页、双页；外屏或窄窗口不会硬塞两页。

02

漫画与文字

支持 EPUB 图像 spine、TXT 编码识别；漫画与长篇文字都能读。

03

护眼与纸张颗粒

暖色滤镜与阅读页颗粒，强度可调，长时间阅读更舒服。

04

书签与快速跳转

进度条圆点直接跳页；文字书的书签以字符位置保存。

05

双指缩放

漫画页支持 1×–4× 缩放，放大后可单指拖动。

06

三语与 Material 3

繁中、简中、English 即时切换；支持深色模式与现代界面。

FOLDABLE & TABLET

一个版面，不被设备绑死

Soreada 根据当前窗口宽高决定版面，不绑定特定机型；展开、折叠、旋转都会保留当前页。

  • 内屏竖向：完整一页，白色留白
  • 内屏横向／平板宽屏：左右双页
  • 外屏／窄窗口：保持单页
  • 展开、折叠、旋转：保留页码，文字重新排版

SCREENSHOTS

界面与排版示意

书库、第一次开书提示，与折叠屏横向双页。

FAQ

常见问题

真的免费吗？

是。Soreada 是 MIT 授权的开源项目，没有广告、订阅或付费墙。

支持哪些格式？

EPUB 2/3 与 TXT。目前不支持 DRM、CBZ/CBR、PDF。

支持折叠屏和平板吗？

支持。内屏竖向单页、横向双页；平板宽屏也是双页，外屏保持单页。

书库会同步吗？

书库存在设备本地，不需要账号；换设备需重新导入。

如何反馈问题？

到 GitHub Issues 开 Issue，附上设备型号、Android 版本与复现步骤。
